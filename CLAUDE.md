# CLAUDE.md — «Фабрика Снов»

Проект: симулятор для Roblox (Luau), клиент-серверная модель, синхронизация файлов через Rojo.
Полное ТЗ: [docs/02-ТЗ-Фабрика-Снов.md](docs/02-ТЗ-Фабрика-Снов.md). Настройка агентов/скиллов: [docs/03-Claude-Code-агенты-и-скиллы.md](docs/03-Claude-Code-агенты-и-скиллы.md).

## Архитектурные принципы (обязательны для любого кода в этом репозитории)

1. **Сервер авторитетен всегда.** Клиент не хранит и не считает валюту/редкость/шансы — только отображает данные, присланные сервером, и отправляет намерения (intent) через RemoteEvents. Любая цена, награда или ролл вероятности пересчитывается на сервере заново — клиентским цифрам не доверяем никогда.
2. **Модульность.** Каждая система — отдельный ModuleScript с чётким публичным API (`Init`, на входе — Player/данные, на выходе — события/результат). Системы не лезут напрямую во внутренности друг друга — только через опубликованный интерфейс или `Signal`.
3. **Данные декларативны, конфиги отдельно от логики.** Цены апгрейдов, редкости петов, параметры биомов и монетизации живут в `src/shared/Config/*.luau`, а не хардкодятся в системах — баланс правится без переписывания кода.
4. **Идемпотентность транзакций.** Любая операция, тратящая валюту или выдающая предмет, — единая функция с проверкой достаточности средств и атомарной записью, без разрыва на шаги, уязвимого к эксплойту/рассинхрону.

## Структура репозитория

```
src/
├── server/            # серверная логика (источник истины)
│   ├── Systems/        # CollectionSystem, FactorySystem, PetSystem, RebirthSystem,
│   │                    # ChaosBossSystem, PvPRaidSystem, MonetizationSystem, DataSystem
│   ├── Services/        # ProfileStoreService и т.п.
│   └── Config/          # server-only конфиги (шансы редкости/мутаций петов) — клиенту не реплицируются
├── client/             # только отображение + intent-запросы к серверу
│   ├── UI/
│   └── Controllers/
├── shared/
│   ├── Config/          # декларативные данные (баланс, цены, шансы)
│   ├── Types.luau       # общие типы (--!strict)
│   ├── Remotes.luau     # централизованный реестр RemoteEvent/Function
│   └── Signal.luau
└── tests/               # юнит-тесты чистых модулей экономики
```

Тесты вне Studio: `lune run src/tests/run` из корня репозитория (lune ставится через rokit: `rokit add lune-org/lune`). Раннер подхватывает все `src/tests/*.spec.luau`; обвязка с подменой `game`/`task`/DataStore — `src/tests/lib/Harness.luau`.

Rojo-проект: [default.project.json](default.project.json).

## Субагенты
